This mod addresses a vanilla issue with the Ford cars from Road Trip where applying the engine brake would cause cars to downshift. You'll also no longer be able to manipulate the engine brake using the decrease/increase keybinds. However, the engine brake indicator will still appear in the indicator widget if you press the engine brake keybind.

This should be compatible with sound mods that overwrite the existing "sound.sui" file.
